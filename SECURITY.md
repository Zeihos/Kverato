# Безопасность КВЕРАТО

Безопасность игровых сохранений и токенов — обязательная часть разработки.

## Что нельзя публиковать

- Токены VK, Telegram, Discord и содержимое файлов .env.
- SQLite-базы игроков, личные данные участников и резервные копии.
- Технические журналы, содержащие приватные идентификаторы или секреты.

Если токен случайно попал в публичный репозиторий, **немедленно перевыпустите его** через соответствующую платформу. Простого удаления из последнего коммита недостаточно: секрет может остаться в истории Git.

## Как сообщить об уязвимости

Не раскрывайте уязвимости, токены или чужие пользовательские данные в публичных Issues и Pull Request. Свяжитесь с владельцем репозитория через [профиль GitHub](https://github.com/Zeihos). Если для репозитория включена функция **Private vulnerability reporting**, используйте её.

Обычные баги без секретов можно сообщать через [Issues](https://github.com/Zeihos/Kverato/issues).

## Техническая проверка

GitHub Actions проверяет, что в Git не добавлены известные типы приватных файлов. Эта проверка **не заменяет** ручную проверку изменений на случайно вставленные токены, которые могут находиться внутри обычного исходного кода.
