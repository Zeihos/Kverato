# Частые вопросы

[← На главную](../README.md)

### Можно ли запустить все три версии одновременно?

Да. VK, Telegram и Discord — разные процессы со своими токенами и базами SQLite. Но два экземпляра одного бота с одной базой запускать не следует.

### Нужен ли сайт?

Нет. Боты работают в сообщениях соответствующих платформ. Компьютер или сервер с ботом должен оставаться включённым.

### Какая версия Python нужна?

Для штатных Windows-запускателей рекомендуется **Python 3.12**.

### Где получить токен?

- VK: в настройках API вашего сообщества.
- Telegram: у [@BotFather](https://t.me/BotFather).
- Discord: в [Discord Developer Portal](https://discord.com/developers/applications).

Токен записывается только в локальный файл .env, созданный из .env.example. Никогда не отправляйте его в чат или публичный Issue.

### Где находятся сохранения?

Каждая версия использует свою SQLite-базу в папке data/. Путь задаётся переменной KVERATO_DB_PATH.

### Можно ли перенести баланс с одной платформы на другую?

Автоматического переноса нет. Простое копирование SQLite между платформами не является поддерживаемой миграцией.

### Как обновиться без потери прогресса?

Остановите старого бота, сделайте резервную копию .env и SQLite, распакуйте обновление отдельно и перенесите сохранения только в ту же платформу. См. [инструкцию](INSTALLATION.md).

### Почему в игровом коде есть v04.py — v16.py, хотя релиз 1.0?

Это действующие модули игрового ядра, а не старые архивы. Без проверки зависимостей удалять их нельзя.

### В Discord не появляются slash-команды. Что делать?

Проверьте, что приложение установлено на сервер с доступом applications.commands. Глобальная регистрация команд может занять некоторое время; проверьте журнал запуска.

### Бот выдаёт ошибку при запуске

Проверьте установку зависимостей, файл .env, версию Python и путь к SQLite. Не удаляйте базу ради повторной установки. Если проблема сохраняется, [создайте отчёт об ошибке](https://github.com/Zeihos/Kverato/issues/new/choose) без токенов и личных данных.
