# Устройство проекта КВЕРАТО

## Три платформы — три самостоятельных запуска

- **bots/vk** — команды сообщества и вложения через VK API.
- **bots/telegram** — Telegram Bot API, личные сообщения, групповые команды и интерактивные кнопки.
- **bots/discord** — Discord Gateway, slash-команды и компоненты интерфейса.

Каждый бот запускается своим **main.py**, использует **.env** и отдельную базу **data/*.sqlite3**. Игровые аккаунты платформ автоматически не объединяются.

## Игровое ядро

В каждой папке расположен пакет **kverato/**:

| Модуль | Назначение |
|---|---|
| db.py | Таблицы, доступ к SQLite и данные игроков |
| service.py | Обработка игровых команд |
| operations.py | Проверка SQLite и резервные копии |
| catalog.py | Игровые каталоги |
| image_cards.py | Генерация графических карточек |
| version.py | Номер версии |
| v04.py … v16.py | Действующие модули игровых механик, а не старые ZIP-сборки |

Платформенные адаптеры, обработчики кнопок и поддерживающие модули находятся рядом с ядром в своей папке.

**Важно:** ядро пока намеренно существует в трёх копиях. Не заменяйте его общей библиотекой без проверки обратной совместимости, миграций SQLite и сохранения экономики.

## Архивы и исходный код

В **releases/v1.0/** находятся исторические релизные ZIP. Они не изменяются при обычной разработке; в **bots/** лежат исходники, пригодные для Git diff и Pull Request.

В **branding/** находятся фирменные изображения. **tools/** содержит проверки, запускаемые без токенов и без изменения реальных пользовательских баз.

## Контроль качества

GitHub Actions проверяет:

1. Состав и целостность архивов 1.0.
2. Соответствие общего релиза отдельным архивам.
3. Python-синтаксис исходников.
4. Регистрацию, профиль, баланс и однократную ежедневную награду на временных SQLite-базах.
5. Отсутствие известных приватных форматов среди отслеживаемых файлов.

Это **smoke-тесты**, не полная проверка API или длительной серверной нагрузки. Перед публикацией новой версии нужны тесты в соответствующей платформе.
