# План развития КВЕРАТО

[← На главную](../README.md)

Это направления работы, а не сроки выхода новых релизов. Главный приоритет — стабильность и сохранность игрового прогресса.

## Основа проекта: релиз 1.0

- [x] Отдельные версии VK, Telegram и Discord
- [x] Игровое ядро с экономикой и персонажами
- [x] Графические карточки и платформенный интерфейс
- [x] Отдельные SQLite-базы
- [x] Исходники и архивы первого релиза на GitHub
- [x] Базовая проверка GitHub Actions

## Ближайшие задачи

- [ ] Расширить регрессионные тесты покупок, переводов и параллельных операций
- [ ] Улучшить тесты Telegram/Discord-кнопок и VK-вложений
- [ ] Тестировать миграции SQLite на безопасных копиях схем данных
- [ ] Улучшить диагностику и восстановление после сбоев
- [ ] Согласовать сообщения об ошибках и навигацию между платформами

## Дальнейшее развитие

- [ ] Сократить дублирование игрового ядра после проверки совместимости
- [ ] Расширить автоматические проверки Windows-сборок
- [ ] Подготовить регламент новых релизов и журнал изменений
- [ ] Оптимизировать генерацию графических карточек

Пункты **[ ]** — планы, а не готовые функции. Даты и версии им заранее не назначены.

Предложить идею можно через [Issues](https://github.com/Zeihos/Kverato/issues/new/choose).
