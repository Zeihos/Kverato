# Установка и обновление КВЕРАТО

КВЕРАТО состоит из **трёх самостоятельных ботов**, каждый со своим токеном и базой SQLite. **Архивы 1.0 — стабильный релиз; исходники 1.1.0-dev.5 — тестовая версия, не предназначенная для замены работающих ботов без проверки.** Рекомендуемая система для приложенных BAT-файлов: **Windows, Python 3.12**.

## Первый запуск

| Платформа | Папка | Токен в .env | ID владельца |
|---|---|---|---|
| VK | bots/vk | VK_TOKEN | KVERATO_OWNER_IDS |
| Telegram | bots/telegram | TELEGRAM_TOKEN | TELEGRAM_OWNER_IDS |
| Discord | bots/discord | DISCORD_TOKEN | DISCORD_OWNER_IDS |

1. Установите Python 3.12 и убедитесь, что команда **py -3.12 --version** работает в Windows.
2. Скопируйте **.env.example** в **.env** внутри папки выбранного бота.
3. Вставьте токен, полученный у официальной платформы, и свой числовой ID владельца.
4. Дважды щёлкните **install_vk_windows.bat**, **install_tg_windows.bat** или **install_discord_windows.bat**, в зависимости от платформы.
5. Запустите **start_vk.bat**, **start_tg.bat** или **start_discord.bat**.
6. Проверьте команду профиля и выдачу ежедневной награды через реальный чат или сервер.

Запускатели работают из соответствующей папки бота. Не запускайте одновременно два экземпляра **одного** бота с одной базой SQLite.

## Обновление без потери прогресса

1. Остановите действующий процесс бота.
2. Сделайте копию **.env** и базы SQLite из подкаталога **data/**.
3. Получите новую сборку отдельно от рабочей папки.
4. Перенесите свою конфигурацию и базу в ту же платформу новой сборки.
5. Запустите установщик при изменении зависимостей; затем запустите бота.
6. Проверьте запуск, профиль, баланс, ежедневную награду и отправку карточек.

**Не переносите VK-базу в Discord или Telegram**: сохранения самостоятельны, миграции между платформами не предусмотрены.

## Работа 24/7

Используйте соответствующий **start_vk_24x7.bat**, **start_tg_24x7.bat** или **start_discord_24x7.bat** вместо обычного запускателя. Держите включённым только один режим запуска на платформу.

## Если бот не стартует

- **Python / виртуальное окружение:** сначала запустите установщик нужной платформы.
- **Токен не задан:** проверьте значение соответствующего токена в .env и отсутствие лишних кавычек.
- **Два процесса:** завершите предыдущий экземпляр бота.
- **Команды Discord не видны:** проверьте, добавлено ли приложение на сервер с разрешением applications.commands.
- **Картинка не отправляется:** проверьте разрешения бота, затем сохраните диагностическое сообщение без токенов.
- **SQLite не проходит проверку:** не удаляйте базу. Остановите бота и восстановите данные из проверенной резервной копии.

Токен, файл .env и саму базу игроков **никому не пересылайте**. Для отчёта об ошибке достаточно очищенного лога и описания действий.
