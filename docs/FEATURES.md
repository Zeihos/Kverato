# Возможности КВЕРАТО

[← На главную](../README.md)

КВЕРАТО — игровая система внутри чатов ВКонтакте, Telegram и Discord. Функции разделены на игровое ядро и платформенный интерфейс.

## Игровые механики

| Раздел | Описание |
| :-- | :-- |
| Персонаж | Регистрация, профиль, игровой опыт, уровень и статистика |
| Экономика | Виртуальные монеты, работа, ежедневные награды, переводы; недельный бонус в разрабатываемой версии 1.1-dev |
| Покупки | Магазин, инвентарь и игровые каталоги |
| Имущество | Дома, транспорт, бизнесы |
| Сообщество | Кланы, социальные взаимодействия, репутация |
| Соревнования | Дуэли, игры, турниры и таблицы лидеров |
| Прогресс | Достижения и сезонные активности |
| Администрирование | Внутренние команды с ограничением по ID владельца |

**Важно:** отдельные команды и интерфейсы могут отличаться между платформами. Этот документ не заменяет справку внутри самого бота.

## Чем отличаются платформы

### ВКонтакте

Работает через сообщения сообщества. Поддерживает игровые команды, генерацию графических карточек и резервный способ отправки вложений при проблемах с фотографиями.

### Telegram

Работает через Telegram Bot API. Помимо команд доступны кнопочные меню, настройки отображения карточек, друзья и рейтинги.

### Discord

Использует slash-команды и компоненты интерфейса. Реализованы игровые карточки, дуэли, друзья, рейтинги, меню и функции владельца с проверкой Discord ID.

## Еженедельная награда (в разработке, 1.1-dev)

Команда `неделя` или `/weekly` начисляет **1 000 игровых монет** один раз в 7 суток. Таймер не зависит от ежедневного бонуса, а выдача фиксируется в отдельной таблице SQLite и защищена от параллельных повторных запросов. Если кошелёк заполнен, награда не списывается и не считается полученной.

**Это функция исходников 1.1.0-dev.1, а не официальных архивов 1.0.**

## Принципы экономики

- Валюта существует только внутри игры и не является реальными деньгами.
- Игровые операции должны выполнять начисления и списания однократно.
- Новые функции проверяются на временных, а не рабочих SQLite-базах.
- Балансы VK, Telegram и Discord автоматически не объединяются.
