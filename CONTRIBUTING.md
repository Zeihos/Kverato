# Разработка КВЕРАТО

КВЕРАТО развивается в трёх самостоятельных версиях: VK, Telegram и Discord. Благодарим за предложения по улучшению.

## Перед изменениями

1. Определите платформу: **bots/vk**, **bots/telegram**, **bots/discord**.
2. Не редактируйте ZIP-файлы первого релиза: это архивные поставки 1.0.
3. Не объединяйте игровые базы разных платформ.
4. Не добавляйте в Git реальные файлы .env, токены или базы игроков.
5. Для новых игровых операций проверяйте однократное начисление и списание валюты.

## Локальная проверка

Требуется Python 3.12. Из корня репозитория:

~~~bash
python tools/release_audit.py
python tools/core_smoke.py
python -m compileall -q bots
~~~

Тесты используют временные базы данных, а не реальные сохранения пользователей. Для проверки конкретной платформы установите её зависимости из requirements-файла в отдельном виртуальном окружении.

## Pull Request

Опишите, что изменилось, какую платформу затрагивает изменение, как вы его проверили и требуется ли перенос SQLite-схемы. При изменении игровой экономики укажите возможный эффект для существующих игроков. Изменения, затрагивающие реальный VK/Telegram/Discord API, проверяйте на тестовом сообществе или сервере.

Обычные ошибки можно оформить через [Issues](https://github.com/Zeihos/Kverato/issues). Для сообщений об уязвимостях используйте [SECURITY.md](SECURITY.md).
